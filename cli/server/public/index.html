mopot
Setup Wizard — 5 steps to autonomous deploys

Step 1 — UiPath Connection

Connect to your UiPath Automation Cloud. A free Community Edition account works.

Generate at cloud.uipath.com → Profile → Access Tokens (scopes: OR.Execution, OR.Assets)

Step 2 — Anthropic API Key

Claude powers the testing, fixing, and asset generation steps.

Get your key at console.anthropic.com

Step 3 — GitHub

Mopot reads your repo, commits fixes, and opens Pull Requests on your behalf.

Generate at github.com/settings/tokens — needs repo scope

Step 4 — Google Play Store

Paste your Google Cloud service account JSON to enable Play Store deployment.

Create in Google Cloud Console → Service Accounts → Keys → JSON. Then grant Release Manager in Play Console → Setup → API access.

Step 5 — Flutter Project

Tell Mopot where your Flutter app lives and which branch to watch.

Run emulator -list-avds to see available AVDs
🚀

Mopot is ready!

Your pipeline will trigger automatically on the next push to your repo.

mopot status

To trigger manually:

mopot run
