Setup Wizard — 5 steps to autonomous deploys

Step 1 — UiPath Connection

Connect to your UiPath Automation Cloud. A free Community Edition account works for the hackathon.

How to find your Account URL
  1. Go to cloud.uipath.com and sign in
  2. Your URL is the full address in the browser bar once you're inside your org — e.g. https://cloud.uipath.com/mycompany
  3. Copy everything up to and including the org slug (the last path segment)
Don't have an account? Sign up for free Community Edition →
How to generate a PAT
  1. Go to cloud.uipath.com and sign in
  2. Click your profile icon (top-right) → My Profile
  3. Open the Access Tokens tab
  4. Click Generate New Token
  5. Name: mopot-cli  |  Expiry: 1 year
  6. Resource Orchestrator API Access
  7. Scopes: check OR.Execution, OR.Assets, OR.Settings
  8. Click Generate — copy the token immediately, it won't be shown again
Token starts with rt_

Step 2 — Anthropic API Key

Claude powers the testing, bug-fixing, and release asset generation steps.

How to get an Anthropic API key
  1. Go to console.anthropic.com
  2. Sign in or create a free account
  3. In the left sidebar, click API Keys
  4. Click Create Key
  5. Name it mopot-pipeline
  6. Copy the key immediately — it is only shown once
  7. Make sure a payment method is added under Billing (pay-per-use)
Estimated cost per pipeline run: $0.10 – $0.40 depending on codebase size.
Key starts with sk-ant-

Step 3 — GitHub

Mopot reads your repo, commits fixes on a branch, and opens Pull Requests on your behalf.

How to generate a GitHub token
  1. Go to github.com/settings/tokens/new (link pre-fills the settings)
  2. Set Note to mopot-pipeline
  3. Set Expiration to 1 year
  4. Under Select scopes, check repo (full repo access — required to open PRs)
  5. Click Generate token at the bottom — copy it immediately
Token starts with ghp_ (classic) or github_pat_ (fine-grained)
Where to find this
This is your Flutter app's GitHub repository — the one Mopot will watch for pushes, commit fixes to, and open Pull Requests on.

How to find it:
Open the repo on GitHub. The value is the two parts after github.com/ in the URL:

github.com/thecodedaniel/my-flutter-app

→ enter: thecodedaniel/my-flutter-app

Open GitHub to find your repo →

Step 4 — Google Play Store

Mopot uses a service account to upload your APK and release notes to the Play Store.

How to create a service account and get the JSON (6 steps)
Part A — Create the service account key
  1. Go to Google Cloud Console → Service Accounts
  2. Select or create a project, then click + Create Service Account
  3. Name: mopot-deployer → click Create and Continue → skip role → click Done
  4. Click on the newly created account → open the Keys tab
  5. Click Add Key → Create new key → select JSON → click Create
  6. A JSON file downloads automatically — paste its full contents into the field above
Part B — Grant Play Console access
  1. Go to play.google.com/console
  2. Navigate to Setup → API access
  3. Click Link to a Google Cloud project → choose the same project
  4. Under Service Accounts, find mopot-deployer → click Grant Access
  5. Set role to Release Manager → click Invite user
Where to find your package name
Your package name is the applicationId in your Flutter app's android/app/build.gradle.

It's also visible in the Play Console URL when you open your app:
play.google.com/console/…/app/com.example.myapp/…

Step 5 — Flutter Project

Tell Mopot where your Flutter app lives and which Android emulator to use for testing.

How to find the project path
This is the folder that contains your pubspec.yaml file.

macOS / Linux: open a terminal in your project folder and run pwd
Windows: open File Explorer, navigate to the folder, click the address bar — the full path is shown

Example: /Users/daniel/StudioProjects/my_app
The branch Mopot watches for pushes — usually main or master
How to find your AVD name
Run this command in a terminal to list your installed emulators:
emulator -list-avds

No emulators? Create one in Android Studio → Device Manager → + Create Device.
Recommended: Pixel 9 Pro with API 34 (Google APIs).

The AVD name is exactly what's printed by -list-avds — spaces replaced with underscores, e.g. Pixel_9_Pro
